## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
On 2026-09-29 the owner decided that the site marks every font that has a Nerd Font build, from the Nerd Fonts project or from the font's maker, with an "NF" marker, a legend and a link to the build's page (TASK-2, PLAN-NERD-FONTS.md). The owner would rather show the Nerd Fonts logo than the letters NF. Nerd Fonts' LICENSE covers only its code (MIT) and its patched fonts (OFL 1.1) and says nothing about the logo, so the site uses "NF" until the maintainers agree to the logo's use. As with the Fonts Over Time license request (ruling T4), Claude drafts the request and the owner posts it.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The draft tells the Nerd Fonts maintainers what purelyfreefonts.com is and where the logo would appear: a small marker beside font names in the list, and in each font's details panel beside the link to its Nerd build
- [ ] #2 The draft asks for permission to use the logo that way, and for any conditions such as credit, colours or a minimum size
- [ ] #3 The draft names the channel to post it on (for example a discussion or an issue on github.com/ryanoasis/nerd-fonts), chosen after reading the project's contributing guidelines
- [ ] #4 The owner has approved the draft and posted it; Claude never posts on the owner's behalf, and the link to the post is in this task's notes
